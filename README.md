# Pulse Prism

Pulse Prism is a short-session neon survival game built with Phaser, TypeScript, and Vite.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Controls

- `WASD` or arrow keys: move
- `Space`: dash through threats
- `Shift`: emit a pulse blast
- `Enter`: start or restart a run
